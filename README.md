# 星巴克團購統計

現代簡約風、支援響應式設計（RWD）的單一 `index.html` 團購統計頁。

## 功能

- 飲品選單：咖啡、星冰樂、茶飲及其他分類，可搜尋
- 訂購資訊：訂購人姓名、尺寸（Tall / Grande / Venti）、冰熱、數量
- 備註欄：常用客製化快速點選（少糖、去冰、換燕麥奶等）＋自由填寫
- 統計：總杯數、訂購人數、訂單筆數、品項小計
- 彙整：一鍵複製成 LINE 群組文字，或下載 `.txt`
- 訂單存在瀏覽器 localStorage，依日期分開存放

## 每天自動更新

星巴克官方沒有公開即時菜單 API，因此本頁採用每日機制：

1. 每天第一次開啟時，菜單更新日自動變成當天
2. 今日推薦依日期自動輪換
3. 訂單改存到當天的新清單，不會把昨天的訂單混進今天
4. 要更換正式品項時，編輯 `index.html` 內的 `MENU` 清單並重新發佈即可
