# 星巴克團購統計

現代簡約風、支援響應式設計（RWD）的單一 `index.html` 團購統計頁，支援多人同步點購。

## 功能

- 飲品選單：咖啡、星冰樂、茶飲及其他共 25 款，可搜尋、分類篩選
- 訂購資訊：訂購人姓名、尺寸（Tall / Grande / Venti）、冰熱、數量
- 備註欄：常用客製化快速點選（少糖、去冰、換燕麥奶等）＋自由填寫
- 統計：總杯數、訂購人數、訂單筆數、品項小計
- 彙整：一鍵複製成 LINE 群組文字，或下載 `.txt`

## 多人同步點購

GitHub Pages 本身是靜態網站，無法自己記住多人的訂單，所以多人同步需要一個免費的即時資料庫。本頁已內建 Firebase Realtime Database 程式碼：

1. 到 Firebase Console 建立專案（免費 Spark 方案即可），新增網頁應用程式
2. 建立 Realtime Database，初期規則可先設為測試模式
3. 把 Firebase 設定貼到 `index.html` 內的 `FIREBASE_CONFIG`（取代 `null`），重新發佈後即自動進入同步模式，不需要登入
4. 分享團購代碼或邀請連結（網址加上 `?room=代碼`），同團所有人的新增、刪除都會即時同步

在填入設定之前，頁面會自動用本機模式運作：訂單存在瀏覽器 localStorage，依日期分開存放。

建議的資料庫規則（只允許讀寫 `rooms` 底下的團購資料，知道團購代碼就能讀寫，適合臨時團購，不適合放機密資料）：

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

## 每天自動更新

星巴克官方沒有公開即時菜單 API，因此本頁採用每日機制：每天第一次開啟時菜單更新日自動變成當天、今日推薦重新輪換；團購代碼預設就是當天日期，跨日自動開新團；要更換正式品項時，編輯 `index.html` 內的 `MENU` 清單並重新發佈即可。
